# Ficha cadastral – Flores do Lago Ltda EPP

Formulário on-line de cadastro de clientes e fornecedores do Orquidário Flores do Lago.

## Arquivos
- `index.html` – página do formulário
- `logo.png` – logo do Orquidário Flores do Lago

## Publicação
GitHub Pages: Settings → Pages → Branch `main` / `(root)` → Save.

Os cadastros enviados chegam por e-mail ao escritório contábil responsável.
